# Environment Variables Setup Guide

This project requires environment variables to run properly. Follow these steps:

## Quick Setup

1. **Backend** (`apps/backend/`):

   ```bash
   cp apps/backend/.env.example apps/backend/.env
   ```

   Then edit `apps/backend/.env` with your actual values.

2. **User App** (`apps/user/`):

   ```bash
   cp apps/user/.env.example apps/user/.env.local
   ```

3. **Admin App** (`apps/admin/`):
   ```bash
   cp apps/admin/.env.example apps/admin/.env.local
   ```

## Required Environment Variables

### Backend (`apps/backend/.env`)

- `DATABASE_URL` - PostgreSQL connection string
- `JWT_SECRET` - Secret key for JWT tokens
- `JWT_REFRESH_SECRET` - Secret key for refresh tokens
- `PORT` - Server port (default: 3333)
- `FRONTEND_URL` - User app URL for CORS
- `ADMIN_URL` - Admin app URL for CORS

### Frontend Apps (`apps/user/.env.local` and `apps/admin/.env.local`)

- `NEXT_PUBLIC_API_URL` - Backend API endpoint (default: `http://localhost:3333/api/v1`)

## Security Notes

⚠️ **NEVER commit `.env`, `.env.local`, or any file containing actual secrets to Git!**

✅ Only `.env.example` files should be committed to show the required variables.

The `.gitignore` file is already configured to exclude:

- `.env`
- `.env.local`
- `.env.development.local`
- `.env.test.local`
- `.env.production.local`

## Verification

To verify your .env files are not being tracked:

```bash
git status
```

You should NOT see any `.env` or `.env.local` files in the output.
